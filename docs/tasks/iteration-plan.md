# Loop Engineering Agent — 迭代计划

## 迭代1：基础设施与模型接入
**目标**：搭建项目骨架，实现模型调用能力
**预计周期**：2 天
**任务**：
- TASK-001：项目初始化与构建管线 (XS) — *阻塞项*
- TASK-002：配置管理模块 (M) — *阻塞项*
- TASK-003：终端 UI 工具库 (M) — 可与 T002 并行
- TASK-004：LiteLLM Proxy 客户端 (M) — *核心依赖*
- TASK-005：模型调用流式输出 (S)
- TASK-013：分级权限控制 (M) — 可与 T004 并行

**迭代1交付标准**：能通过 `lea config init` 配置模型，成功调用 LLM 并流式输出到终端。

---

## 迭代2：工作流核心引擎
**目标**：实现工作流状态机、持久化和技能加载
**预计周期**：3 天
**任务**：
- TASK-006：工作流状态机引擎 (L) — *关键路径*
- TASK-007：工作流状态持久化 (M)
- TASK-010：技能解释执行引擎 (L) — 可与 T006 部分并行
- TASK-014：lea resume / lea status (S)

**迭代2交付标准**：能启动工作流、按阶段流转、加载并执行技能、状态持久化并恢复。

---

## 迭代3：上下文管理与子代理
**目标**：实现上下文压缩和子代理隔离，解决核心工程问题
**预计周期**：3 天
**任务**：
- TASK-008：上下文边界压缩器 (XL) — *最高风险*
- TASK-009：子代理隔离引擎 (XL) — *最高风险*
- TASK-016：长时间运行稳定性保障 (M)

**迭代3交付标准**：长执行场景下上下文不溢出、子代理独立执行不污染主控、8小时稳定性验证通过。

---

## 迭代4：自主执行闭环
**目标**：实现完整的工作流自主执行和收敛闭环
**预计周期**：2 天
**任务**：
- TASK-011：自主执行循环 (L)
- TASK-012：lea run 命令集成 (M)

**迭代4交付标准**：`lea run "需求描述"` 能自主执行完整工作流（req→test），Bug 收敛闭环正常工作。

---

## 迭代5：打磨与完善
**目标**：补全 CLI 界面、制品管理、集成测试
**预计周期**：2 天
**任务**：
- TASK-015：CLI 界面完善 (M)
- TASK-017：制品版本管理 (S)
- TASK-018：端到端集成测试 (L)

**迭代5交付标准**：所有 P0/P1 需求通过测试，跨平台验证通过，可发布 v0.1.0。
